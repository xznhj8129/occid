A semantic object is a product; an alias is only a name.
  Drone      = Airframe.MULTIROTOR × Controller.UNMANNED × Locomotion.SELF_PROPELLED × PhysicalDomain.AIR × Substrate.MECHANICAL × UnmannedVehicle
  Drone == UAV * Airframe.MULTIROTOR: True
  Geodetic == Representation.Geodetic: True

A chart reduces a quantity in a representation to irreducible variables.
   chart Position * Representation.Geodetic := lat:float[deg] * lon:float[deg] * h:float[m]
   chart Position * Representation.LocalCartesian := x:float[m] * y:float[m] * z:float[m]
   chart Velocity * Representation.LocalCartesian := vx:float[m/s] * vy:float[m/s] * vz:float[m/s]
   chart Attitude * Representation.LocalEuler := roll:float[rad] * pitch:float[rad] * yaw:float[rad]
   chart Attitude * Representation.Quaternion := qw:float * qx:float * qy:float * qz:float
  GlobalPosition: ['lat', 'lon', 'h']

Data is stored in a representation and addressed by meaning.
  uav * Position            -> ['GlobalPosition', 'LocalPosition']
  uav * Position * Geodetic -> GlobalPosition(lat=36.53044, lon=-83.216383, h=125.0)
  uav * Position * Local    -> LocalPosition(x=120.0, y=-40.0, z=15.0)

Facts are independent; no aggregate type covers them.
   uav * Velocity * LocalCartesian -> LocalVelocity(vx=12.0, vy=0.0, vz=-1.5)
   uav * Attitude * LocalEuler     -> LocalAttitude(roll=0.0, pitch=0.0, yaw=1.57)

A task is an open expression: fixed factors + typed free variables.
  MOVE = MOVE(actor: Entity, destination: Position)  { Position(actor) = destination }
  fixed semantics: Realm.WORLD × Task × TemporalMode.ACHIEVE
   MOVE(actor=?, destination=?)
   MOVE(actor=uav-1, destination=?)
   MOVE(actor=uav-1, destination=mark-alpha) unbound: []

An unbound variable is an unknown, not an error.
   LOCATE(target=target-42) => position=?
   no position fact yet -> solve() = {}
   fact arrives         -> solve() = {'position': GlobalPosition(lat=36.53014, lon=-83.216683, h=90.0)}

Relations connect independent things; roles belong to the relation.
   AssignedWork(assignee=uav-1, work=task-move-1)

Legality is derived from declared constraints, never enumerated.
  Drone * BloodGroup.A_POS : False
  Machine * Actor          : False
  Mission * AIR * Altitude : True
  Mission * SEA * Altitude : False
  Drone entails Machine * Controller.UNMANNED * AIR: True
